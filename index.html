Why PolyClaw

Your workflow. Your models. Your code.

PolyClaw keeps the assistant close to your development environment while giving you the freedom to choose how intelligence is delivered.

⚡

Model freedom

Switch between local models and hosted providers without rebuilding your entire workflow around one vendor.

✂️

Tool-assisted coding

Read files, inspect project structure, run development commands, and prepare focused edits through explicit tool calls.

🔒

Privacy by design

Run through local infrastructure when privacy matters. You decide which provider receives a request and what leaves your machine.

🧩

Works with your stack

PolyClaw lives in the terminal, alongside Git, package managers, test runners, shells, and the rest of your existing toolkit.

🛠️

Transparent actions

See what Poly is doing as it works. Commands, file reads, and proposed changes are surfaced directly in the session.

🌍

Community-owned

Free and open source under the MIT License. Inspect the code, improve it, fork it, and build the assistant you need.

Meet the mascot

Poly the Red Crab

Poly is a terminal-bound coding companion with sharp claws for precise edits and a hard shell for a privacy-conscious workflow.

  • 🦀 Snip and splice: work with focused files and reviewable changes.
  • 🦀 Hardened shell: keep commands visible and under your control.
  • 🦀 Adaptive intelligence: choose the model that fits the task.
🦀

// Poly status

const poly = new PolyClaw({

mode: 'model-agnostic',

localFirst: true,

clawsSharp: true

});

poly.scuttle(); // ready

Unleash the crab in your terminal

Install PolyClaw globally, connect it to your preferred model provider, and bring an open coding assistant into your terminal.

npm install -g polyclaw-cli
